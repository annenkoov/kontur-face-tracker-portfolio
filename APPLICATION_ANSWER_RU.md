# Ответ о проекте для отклика

С помощью Codex я собрал учебный проект «Контур» — приложение для Windows на Python, которое получает изображение с веб-камеры, анализирует мимику и показывает, как сигналы меняются относительно моей короткой личной калибровки. В приложении есть предпросмотр камеры, калибровка, график и локальная история сессий. Это экспериментальный трекер изменений мимики, а не медицинский измеритель стресса.

Я формулировал задачи для AI, запускал приложение на компьютере, проверял результат и сообщал, что работает неправильно. Например, при задержке анализа пропадало изображение с камеры. Я сообщил об этом, после чего вместе с Codex мы поправили обработку пустых и задержанных кадров, чтобы видеопоток не очищался из-за временной паузы анализа. Ещё я попросил отделить определение закрытых глаз от распознавания эмоций: состояние глаз стало показываться отдельно и подтверждаться по нескольким кадрам.

Сейчас приложение запускается локально на Windows. Основная версия использует Qt Quick/QML; отдельно сохранены форк интерфейса и форк на Kirigami. Проект пока учебный: качество определения эмоций и связь этих сигналов со стрессом не подтверждены клинически.
